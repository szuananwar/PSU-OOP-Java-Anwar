WEBSITE: index.html

HOW TO PUBLISH ON GITHUB PAGES
1. Create a NEW public GitHub repository named PSU-Java-OOP-Lab (separate from your C++ website).
2. Upload index.html to the repository root. (README.txt is optional.)
3. Open Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. After the Pages deployment succeeds, the address will be:
   https://YOUR-GITHUB-USERNAME.github.io/PSU-Java-OOP-Lab/
5. Share that actual published URL with students via Blackboard.

FEATURES
- 100 guided Java exercises in 33 topics: System.out print/println/printf, Scanner,
  parsing, JOptionPane, equations, selections, loops, methods, classes, objects,
  constructors, getters, setters, arrays, and small complete programs.
- Blocks ordinary paste and drag-drop into the answer editor; cannot prevent all cheating.
- Shows mistakes, one reference answer, hints, and follow-up questions.
- Local browser progress tracking and .txt report download (not a secure gradebook).
- Requires no server or Java installation to use.

IMPORTANT TEACHING LIMITATIONS
This checks beginner Java syntax against guided patterns. It does NOT execute Java,
perform full semantic analysis, or guarantee every legal alternative is accepted.
Some incorrect solutions may also accidentally match guided patterns.
Do not use as a sole high-stakes grading tool. Students can contact the instructor
if an alternative solution is valid but is flagged.
